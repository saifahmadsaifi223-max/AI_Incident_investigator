# AI Incident Investigator

An agentic AI system designed to investigate software incidents
using logs, metrics, deployment information, historical incidents,
and evidence-grounded reasoning.

## Objective

The system will:

1. Ingest incident data
2. Analyze logs and metrics
3. Retrieve relevant historical incidents
4. Investigate possible causes
5. Gather supporting evidence
6. Identify potential root causes
7. Verify the investigation
8. Generate an evidence-grounded incident report
